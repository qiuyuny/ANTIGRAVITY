The binary heap

An array in disguise · How contiguous memory mimics a lightning tree
[!!!] CORE MUST-KNOW COMP20003 IN-SCOPE · 15-20 MARKS
A priority queue is one of computing's greatest triumphs: an abstract data type where urgent jobs float instantly to the top, like air bubbles through water. From emergency room triage to CPU interrupt scheduling, the highest priority task always commands attention.
Yet storing this hierarchy posed a physical crisis. Plain unsorted lists allow instant insertions but turn finding the minimum into an agonizing linear scan. Fully sorted lists allow instant extraction, but every single insertion triggers a brutal domino shift.
The Commuter Jam (Sorted Array)
Squeezing a key into a sorted array is like pushing onto a packed morning commuter train. Every single person behind must shuffle right: O(N) bottleneck!
The Royal Elevator (Binary Heap)
The Root is King (global maximum at index 0 in O(1) time). Subordinate nodes only need to beat their direct parent, bubbling upward in O(log N) speed!

PRO-TIP · INSTANT LEAF FORMULA
When an exam asks: "Which array indices hold leaves?", NEVER draw the tree! In a 1-based heap of size N, leaves are ALWAYS at indices ⌊N / 2⌋ + 1 to N. Last internal node is always ⌊N / 2⌋. That's a free 2 marks in 5 seconds!

Key Milestones
1964 · J.W.J. Williams
Invents the binary heap to deliver the first in-place O(N log N) HeapSort.
1964 · Robert W. Floyd
Proves bottom-up `MakeHeap` builds a heap from raw data in linear O(N) time.
1975 · Graph Routing
Becomes the engine of Dijkstra's algorithm, powering network routing worldwide.
EXAMINER NOTE · ASYMMETRY
Up-heap requires only 1 comparison per level (against parent).
Down-heap requires 2 comparisons per level (pick largest child first, THEN compare with parent)!
EXAMINER FULL-MARK SCORING CRITERION

Q: Why is an array preferred over a linked list for binary heaps?
"A complete binary tree mapped to an array computes parent and child addresses in O(1) arithmetic time (⌊(i-1)/2⌋, 2i+1). A linked list lacks random access, requiring O(N) sequential traversal to find the insertion tail or parent, degrading insertion from O(log N) to O(N)."
