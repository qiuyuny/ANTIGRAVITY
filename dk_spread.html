The binary heap

A priority queue is one of computing's most vital inventions: an abstract data structure where every entry carries an urgency rank, ensuring the most pressing task is always served first. Unlike a simple first-in, first-out line, priority queues dynamically reorder incoming work.
Implementing this concept efficiently, however, posed a profound dilemma. Storing items in an unsorted list allows instantaneous insertions but makes locating the minimum a tedious chore. Keeping the list sorted reverses the problem: extraction is instant, but insertion grinds to a halt.

Key Milestones
1964 · J.W.J. Williams
Invents the binary heap to deliver the world's first in-place O(N log N) HeapSort.
1964 · Robert W. Floyd
Discovers bottom-up heap construction, building heaps from raw arrays in linear O(N) time.
1975 · Graph Routing
Becomes the engine of Dijkstra's algorithm, powering network routing protocols worldwide.
