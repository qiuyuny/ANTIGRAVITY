UP-HEAP ASYMMETRY RULE
Comparisons per level = exactly 1.
Why? A node only has one direct parent. It never looks at its sibling. Worst-case comparisons ≤ ⌊log&sub2; N⌋ = 2 comparisons for N = 7!
CHEATSHEET RAPID ANCHOR
• Leaf Indices: ⌊7/2⌋ + 1 = 4 → Indices 4, 5, 6, 7 are leaves.
• Formulas Table: See COMP20003_Full_Exam_Spec.pdf §4.2.2.
• 0-Based Trap: If root is 0, parent of 7 is ⌊(7-1)/2⌋ = 3.

DOWN-HEAP ASYMMETRY RULE
Comparisons per level = exactly 2.
• Comparison 1: Compare left vs right child to pick the winner.
• Comparison 2: Compare the winner against the parent node.
LETHAL 0-MARKS TRAP
Pitfall: Writing Floyd takes O(N log N) because it calls downheap N/2 times.
Full Mark: Height is low for most nodes! ∑ (h / 2h) converges to 2 → strict Θ(N) linear time.
